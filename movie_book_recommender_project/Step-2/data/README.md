# مستندات گام دوم: ساختار داده و محیط سیستم پیشنهاددهنده

## ۱. منبع داده و بررسی مجوز (Source & License)
- **منبع داده:** ساختار امتیازدهی استاندارد فیلم و کتاب الهام‌گرفته از MovieLens و Goodreads.
- **مجوز (License):** دارای مجوز Open Source MIT جهت استفاده آموزشی و پژوهشی.

## ۲. توصیف فیلدهای جداول
### جدول `ratings.csv`:
- `user_id`: شناسه یکتای کاربر
- `item_id`: شناسه اقلام (فیلم یا کتاب)
- `item_type`: نوع قلم (movie / book)
- `rating`: برچسب امتیاز عددی گسسته بین ۱ تا ۵
- `timestamp`: برچسب زمانی تعامل

### جدول `items.csv`:
- `item_id`: شناسه آیتم
- `title`: نام اثر
- `type`: نوع (movie / book)
- `genre`: دسته‌بندی موضوعی
- `release_year`: سال انتشار

## ۳. مشخصات ماتریس و مجموعه آزمون
- **تقسیم داده‌ها:** ۸۰٪ آموزش (`train.csv`) و ۲۰٪ آزمون ارزیابی مدل (`test.csv`)
- **ماتریس کاربر-آیتم:** ایجادشده با دستور Pivot در اسکریپت لودر
- **تراکم و پراکندگی (Sparsity):** ۵۰٪ مقادیر ناموجود به دلیل مشاهده‌پذیری جزئی در سیستم توصیه‌گر
